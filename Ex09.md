# Bài 9: Prompt 3 thành phần giải mã lỗi trạm sạc VoltCharge

## Phần 1: Thiết kế Prompt

### 1. Vì sao AI trả lời sai?
Câu hỏi "phần mềm bị hỏng rồi" **thiếu ngữ cảnh và thiếu log lỗi**, nên AI phải **đoán mò** theo kịch bản phổ biến (trạm sạc hỏng → dây điện) và trả lời tự tin nhưng sai. Đây là **Hallucination**.

## Phần 2: Giải mã & khắc phục

### 3. Giải thích lỗi
Phần mềm trạm sạc muốn ghi file `session.log` vào thư mục `Program Files` (được Windows **khóa bảo vệ**) nhưng **không có quyền Quản trị viên** nên bị từ chối (`Access is denied`, exit code 5). Phần mềm không khởi động được → trụ ngừng sạc.
**Kết luận:** lỗi **phân quyền phần mềm**, không phải hỏng phần cứng.

### 4. Ba bước xử lý trên Windows 11
1. **Chạy với quyền Admin:** chuột phải VoltCharge → **Run as administrator** → **Yes**.
2. **Cấp quyền ghi thư mục `data`:** chuột phải `C:\Program Files\VoltCharge\data` → **Properties** → **Security** → **Edit** → chọn tài khoản chạy app → tick **Modify/Write** → **Apply**.
3. **Đặt chạy Admin vĩnh viễn:** chuột phải file `.exe` → **Properties** → **Compatibility** → tick **Run this program as an administrator** → **Apply**, rồi khởi động lại và thử sạc.

### 5. Bẫy an ninh: `API_KEY: volt_secret_token_889922`
**Xử lý:** xóa hoặc thay bằng `API_KEY: [REDACTED]` trước khi dán.
**Lý do:**
- Nội dung chat gửi lên **máy chủ bên thứ ba** → nguy cơ lộ bí mật.
- Kẻ xấu có key có thể **truy cập trái phép** hệ thống.
- AI **không cần key** để giải thích lỗi này.
- Lỡ gửi rồi → **thu hồi/đổi key ngay**.
